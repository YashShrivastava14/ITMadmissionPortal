# College Admission Portal

A web-based portal designed to streamline the college admission process using HTML5, CSS3, and JavaScript.

## Features

- Student registration and login
- Course selection interface
- Form validation
- Responsive layout using Bootstrap
- Dynamic interaction with JavaScript

## Technologies Used

- *HTML5* – Structure of the web pages
- *CSS3* – Styling and layout
- *JavaScript* – Form validation and interactivity
- *Bootstrap* – Responsive design
- *Node.js & Express.js* – Backend server for handling routes or serving the project
